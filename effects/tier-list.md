# tier-list

A tier list drops in and your item flies into S tier.

**Best for:** Rankings, comparisons, 'the best X'.  
**Typical length:** 3–5 s

## Fill it from the transcript

- `title` = what is ranked; `item` = their winner; `others` = the alternatives they mention.

## Options

| Option | Meaning |
|---|---|
| `title` |  |
| `item` | winner |
| `others` | others with &#124; |

## Example plan entry

```json
{"fx": "tier-list", "start": 1.0, "end": 6.0, "title": "AI editors", "item": "Claude"}
```
