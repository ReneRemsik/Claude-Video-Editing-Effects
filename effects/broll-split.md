# broll-split

B-roll on top with a price-tag sticker, you below.

**Best for:** Talking about a product, place or result.  
**Typical length:** 2–4 s

## Fill it from the transcript

- `text` = the price/claim they say ("4 hrs → 4 min"); `images` = supplied b-roll.

## Options

| Option | Meaning |
|---|---|
| `images` | folder |
| `text` | tag |
| `pick` | which image |

## Example plan entry

```json
{"fx": "broll-split", "start": 1.0, "end": 5.0, "text": "4 hrs  →  4 min"}
```
