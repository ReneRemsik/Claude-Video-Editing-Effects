# countdown-flip

A 3-2-1 flip clock above your head.

**Best for:** Countdowns, launches, 'in 3 steps'.  
**Typical length:** 3 s

## Fill it from the transcript

- Start 3 s before the reveal they build up to; `from` = how many seconds/steps.

## Options

| Option | Meaning |
|---|---|
| `from` | start number |

## Example plan entry

```json
{"fx": "countdown-flip", "start": 1.0, "end": 5.0}
```
