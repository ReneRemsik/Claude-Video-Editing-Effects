# shortcut-rain

Keyboard keys rain down behind you.

**Best for:** Tech/workflow, shortcuts, 'just press…'.  
**Typical length:** 1.5–3 s

## Fill it from the transcript

- `text` = keys or short commands they mention (cmd, /effects, enter).

## Options

| Option | Meaning |
|---|---|
| `text` | keys joined with &#124; |
| `count` | how many |

## Example plan entry

```json
{"fx": "shortcut-rain", "start": 1.0, "end": 4.0, "text": "cmd|K|/effects|enter"}
```
