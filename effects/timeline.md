# timeline

A dark red film grade with an editing timeline, a REC timecode and a glowing playhead.

**Best for:** Talking about editing, production, behind the scenes.  
**Typical length:** 2–5 s

## Fill it from the transcript

- `text` = short title of what they're making; `sub` = subtitle; `tc` = a timecode if relevant.

## Options

| Option | Meaning |
|---|---|
| `text` | title |
| `sub` | subtitle |
| `tc` | timecode |
| `color` | hex |
| `look` | red |

## Example plan entry

```json
{"fx": "timeline", "start": 1.0, "end": 6.0, "text": "AUTO-EDIT"}
```
